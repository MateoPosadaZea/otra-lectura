# Pulso de los lectores

Valoraciones de un toque que se dejan al final de cada edición
("¿Cómo le quedó esta edición?"). Llegan como issues "[Pulso] …"; la
revisión horaria las anota aquí y cierra el issue. La rutina diaria lee
las últimas para calibrar el largo y la carga de la edición siguiente.

Formato: una línea por valoración, la más reciente arriba.
`AAAA-MM-DD · Edición N · Liviana|Justa|Pesada · quién`
